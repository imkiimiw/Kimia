## فاز ۲ — آنچه ساخته شد (وضعیت واقعی)

- [x] **ترجمه + خلاصهٔ فارسی** با Gemini (یک فراخوانی برای چند خبر): عنوان، متن کوتاه/بلند، نکته‌های کلیدی، نام‌ها با املای اصلی، نقل‌قول‌ها با متن اصلی، ادعاها با شاهد عینی از منبع.
- [x] **دسته‌بندی با AI** (فقط از میان ۱۵ دستهٔ مجاز؛ دستهٔ قاعده‌محور هم نگه داشته می‌شود).
- [x] **importance و confidence اولیه** با جزئیات قابل‌توضیح؛ تک‌منبع حداکثر ۶۹ («گزارش اولیه»)، ردشده در بررسی حداکثر ۴۹.
- [x] **Hallucination guard**: لایهٔ ۱ قطعی (عدد/تاریخ، نام لاتین، موجودیت‌ها، نقل‌قول، شاهد ادعا، فارسی بودن، بدون لینک) + لایهٔ ۲ با AI (verify) + یک بار بازنویسی + در غیر این صورت بررسی انسانی. هرگز خودکار منتشر نمی‌شود.
- [x] **Review در PM** با ✅ تأیید، 📤 انتشار فوری، ✏️ ویرایش (با Reply)، ❌ رد؛ دستورهای `/news /pending /approve /reject /publish /settings`.
- [x] **حالت‌های انتشار** auto / semi / manual برای هر دسته (پیش‌فرض semi)؛ موضوعات حساس در هر حالتی به بررسی انسانی می‌روند.
- [x] **کانال اصلی**: از فاز ۲ مجاز؛ پیش‌فرض همچنان کانال تست تا مالک با `/settings target main` (یا متغیر `WANGER_NEWS_PUBLISH_TARGET`) عوض کند.
- [x] Prompt versioning، ثبت هر فراخوانی AI (توکن، هزینه، نسخهٔ prompt، خطا)، بودجهٔ هر اجرا/روز، cache، دفاع در برابر prompt injection.
- [x] Migration `0002` (upgrade/downgrade روی SQLite و PostgreSQL، با انتقال داده).
- [ ] **تست زنده با Gemini واقعی انجام نشد**: کلید Gemini در این محیط نبود (درخواستش رد شد). کلاینت با پاسخ‌های شبیه‌سازی‌شده تست شده است. اولین اجراهای واقعی را با `/status` و جدول `ai_runs` زیر نظر بگیرید.

## فاز ۳ — آنچه ساخته شد (وضعیت واقعی)

- [x] **Story clustering با embedding** (`gemini-embedding-001`، ۷۶۸ بعد، CLUSTERING): مرحلهٔ CLUSTER بعد از gate؛ قاعدهٔ ترکیبی cosine + نام‌های مشترک + فاصلهٔ زمانی (پنجرهٔ ۷۲ ساعت)؛ dedup سطح ۳. بردارها در ستون pgvector (روی SQLite به‌صورت JSON).
- [x] **یک خلاصه برای هر رویداد از چند منبع** (حداکثر ۵ منبع، معتبرترین اول)؛ ۱۵ دقیقه صبر برای جمع شدن منابع (خبرهای اولویت ۱۰۰ صبر نمی‌کنند).
- [x] **استقلال منابع**: هم‌مالک (`owner_group`)، کپی ثبت‌شده (L1/L2) و متن تقریباً یکسان (کپی خبرگزاری) = یک منبع.
- [x] **Claims/Evidence**: هر ادعا با منبع‌هایی که آن را گفته‌اند و شاهد عینی از متن همان منبع؛ وضعیت قاعده‌محور (تأییدشده / احتمال بالا / تأییدنشده / متناقض / ردشده)؛ جدول‌های `claims` و `evidence`.
- [x] **تناقض**: AI فقط گزارش می‌کند (موضوع + روایت هر منبع با شاهد)، guard هر روایت را با متن منبع خودش (و عددهایش) چک می‌کند؛ جملهٔ ثابت «گزارش‌ها دربارهٔ … متفاوت است؛ … در حالی که …»؛ وضعیت «متناقض» و همیشه بررسی انسانی.
- [x] **confidence چندمنبعی**: تعداد منابع مستقل وارد امتیاز شد؛ سقف‌ها: تک‌منبع ۶۹، تناقض ۶۹، ردشده در guard ۴۹.
- [x] **Update Post**: گزارش مستقل تازه دربارهٔ خبر منتشرشده ← فراخوانی `update` (همان رویداد؟ اطلاعات تازه؟) ← پست «🔄 به‌روزرسانی» به‌صورت Reply به پست قبلی / فقط شمارش به‌عنوان تأیید / جدا شدن به‌عنوان خبر مستقل.
- [x] پست‌های کانال منبع و پست‌های دستی کانال: همان رفتار قبلی (کپی بدون تغییر) + عضو story؛ پست دستی در کانال انتشار، story را «منتشرشده» می‌کند و به‌روزرسانی‌ها به آن Reply می‌شوند.
- [x] کارت بررسی: منابع مستقل، وضعیت ادعاها، «به‌روزرسانی خبر منتشرشده».
- [x] Migration `0003` (upgrade/downgrade روی SQLite و PostgreSQL + pgvector).
- [ ] **کالیبراسیون روی embedding واقعی انجام نشد** (کلید Gemini نبود). آستانه‌ها محافظه‌کارانه‌اند (ادغام اشتباه بدتر از ادغام‌نشدن است) و هر عضویت دلیلش (`cluster_score`) را ثبت می‌کند.

## تصمیم‌هایی که با مالک است

1. **نام کانال‌ها**: کانال تست، کانال اصلی (فاز ۲)، کانال منبع (اگر خصوصی است، شناسهٔ عددی؛ ربات آن را به مالک اعلام می‌کند).
2. **منابع فارسی** (همه فعلاً غیرفعال، فید همه کار می‌کند): بی‌بی‌سی فارسی، DW فارسی، یورونیوز فارسی، ایندیپندنت فارسی، رادیو فردا، صدای آمریکا، ایران اینترنشنال. ایرنا/ایسنا در دسترس نبودند. توضیح مالکیت/بودجهٔ هر کدام در `config/sources.yaml`.
3. **پست‌های کانال منبع**: هنوز همان‌طور که هست کپی می‌شوند و Review/AI نمی‌خواهند (پاسخی دریافت نشد؛ رفتار فاز ۱ حفظ شد). اگر باید از Review بگذرند یا با قالب استاندارد بازنویسی شوند، بگویید.
5. **مدل Gemini**: پیش‌فرض `gemini-3.5-flash-lite` (ارزان‌ترین، سهمیهٔ بیشتر). برای کیفیت بهتر فارسی می‌شود `gemini-3.6-flash` را در `config/pipeline.yaml` گذاشت.
6. **حالت انتشار**: پیش‌فرض semi است (هر خبر کارت بررسی می‌گیرد، حداکثر ۵ کارت در هر اجرا). برای دسته‌هایی که می‌خواهید خودکار باشند: `/settings mode technology auto`.
4. **امتیاز اعتبار اولیهٔ منابع** (`reliability_score`) تخمین اولیه است؛ لطفاً مرور کنید.
