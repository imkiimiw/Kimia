# 🤫 ربات نجوا و پیام ناشناس — فقط روی Telegram Serverless

رباتی سه‌زبانه (فارسی، English، Русский) با **عضویت اجباری** که فقط روی **سرورلس خود تلگرام**
([Telegram Serverless](https://core.telegram.org/bots/serverless)) اجرا می‌شود؛ کد، دیتابیس، وبهوک و مینی‌اپ
همه داخل تلگرام است. بدون VPS، Vercel، Cloudflare، AWS یا GitHub Actions.

این پوشه یک پروژه‌ی **جدا** است، متصل به ربات **@Wanger_Shadowbot**. ربات‌های قبلی در بقیه‌ی مخزن دست نخورده‌اند.

اولین `/start` انتخاب زبان را نشان می‌دهد (بعداً با `/lang` عوض می‌شود). بعد از آن دو بخش هست:
**🤫 نجوا** و **💬 پیام ناشناس**.

## 🤫 نجوا

در هر چتی (گروه یا پی‌وی) بنویسید:

```
@Wanger_Shadowbot متن نجوا @username
@Wanger_Shadowbot متن نجوا 123456789          ← با آیدی عددی گیرنده
```

و روی نتیجه بزنید. در چت پیام «🔒 یک نجوا برای @username» با دکمه‌ی «👁 نمایش نجوا» می‌آید؛ فقط گیرنده(ها) و فرستنده
متن را می‌بینند. پیام داخل چت به زبان فرستنده است و پاپ‌آپ‌ها به زبان کسی که دکمه را می‌زند.

| # | قابلیت | نحوه‌ی استفاده |
|---|---|---|
| 1 | نجوای ساده | `متن @username` یا `متن 123456789` (ارقام فارسی هم قبول است) |
| 2 | چند گیرنده | تا ۳ نفر: `متن @ali @sara 123456789` |
| 3 | دیده شد | با اولین باز شدن توسط گیرنده، پیام داخل چت «👁 دیده شد» می‌گیرد |
| 4 | **خبر هر باز شدن** | **هر بار** که گیرنده نجوا را باز کند، همان لحظه به فرستنده در پی‌وی خبر می‌رسد، با شمارش: «👁 @sara نجوای شما را باز کرد.» ← «… دوباره نجوای شما را باز کرد — بار ۲م.» (خاموش‌شدنی در ⚙️ تنظیمات) |
| 5 | **کنجکاوها** | هر غیرگیرنده‌ای که دکمه را بزند ثبت می‌شود و پیام «👀 کنجکاوها: ۲» می‌شود؛ فرستنده همان لحظه خبر می‌گیرد. **فقط فرستنده و گیرنده(ها)** می‌توانند ببینند چه کسانی کنجکاوی کرده‌اند (دکمه‌ی «👀 کنجکاوها» در جزئیات نجوا)؛ هیچ‌کس دیگر، حتی مالک ربات |
| 6 | یک‌بار مصرف | `!متن @ali` — بعد از اولین دیدن، متن از دیتابیس پاک می‌شود و پیام «🔥 نجوا سوزانده شد» می‌شود |
| 7 | انقضا | `متن @ali 30m` یا `1h` یا `2d` (تا ۷ روز) |
| 8 | نجوای طولانی | متن بیش از ۲۰۰ کاراکتر: دکمه‌ی «📖 خواندن در ربات» فقط برای گیرنده/فرستنده |
| 9 | تاریخچه و ارسال سریع | `/history`: ۲۰ نجوای آخر ارسالی و دریافتی، با تعداد باز شدن. در اینلاین اگر فقط متن بنویسید ۳ گیرنده‌ی اخیر پیشنهاد می‌شوند |
| 10 | بلاک و تنظیمات | `/blocks` و `/settings` (خبر باز شدن، انقضای پیش‌فرض) |

## 💬 پیام ناشناس

| # | قابلیت | توضیح |
|---|---|---|
| 1 | لینک شخصی | `/link`: لینک `t.me/Wanger_Shadowbot?start=a_<code>` با دکمه‌ی اشتراک‌گذاری؛ «🔄 لینک جدید» لینک قبلی را باطل می‌کند؛ «⏸ توقف دریافت» |
| 2 | دریافت و پاسخ | متن، عکس، ویدیو، ویس، استیکر، فایل… زیر هر پیام: «↩️ پاسخ»، «🚫 بلاک»، «🚩 گزارش»، «📂 بیشتر». گفتگو دوطرفه است و طرف ناشناس در هر دو جهت ناشناس می‌ماند |
| 3 | دسته‌بندی | فرستنده قبل از نوشتن یکی را انتخاب می‌کند: ❓ سؤال، 💌 اعتراف، 💬 نظر، 😂 شوخی، ❤️ تعریف، 📝 عمومی (و 🌟 جواب سؤال روز). صاحب لینک می‌تواند دسته را عوض کند |
| 4 | کارت تصویری | مینی‌اپ «🖼 ساخت کارت»: کارت لینک، کارت سؤال روز، یا کارت یک پیام دریافتی همراه با جواب خودتان؛ اندازه‌ی استوری ۹:۱۶، پست ۴:۵ یا مربع، ۶ رنگ، کد QR؛ عکس آماده برای استوری تلگرام و اینستاگرام در چتتان فرستاده می‌شود |
| 5 | سؤال روز | سؤال روزانه (۴۰ سؤال در هر زبان) یا سؤال خودتان؛ بازدیدکننده‌ی لینک سؤال را می‌بیند و جوابش با «🌟» و متن سؤال می‌رسد |
| 6 | فیلتر، بلاک، ضداسپم | فیلتر فحش فارسی/انگلیسی/روسی (با تشخیص کـــشیدن، فاصله‌گذاری، اعداد به‌جای حروف)، فیلتر لینک، کلمه‌های ممنوع خودتان، «فقط متن»، حالت بی‌صدا؛ بلاک بدون فهمیدن هویت؛ محدودیت سرعت |
| 7 | صندوق پیام | `/inbox`: صندوق، 🗄 بایگانی و 🛡 فیلترشده؛ نشانه‌ی نخوانده، فیلتر بر اساس دسته، جستجو (فارسی/روسی/انگلیسی، بدون حساسیت به حروف)، حذف |
| 8 | امتیاز | بازدیدکننده‌ها ۱ تا ۵ ستاره می‌دهند (هر نفر یک رأی، قابل تغییر)؛ با باز کردن لینک میانگین دیده می‌شود: «⭐️ امتیاز: ۴٫۶ از ۵ (۲۳ رأی)». نمایشش خاموش‌شدنی است |
| 9 | عکس لینک | عکسی که صاحب لینک می‌گذارد هر بار با باز شدن لینک فرستاده می‌شود با زیرنویس «💬 در حال ارسال پیام ناشناس به **(اسم)** هستی» |
| 10 | پروفایل محدود | فقط اسم نمایشی (۳۲ کاراکتر)، بیو (۱۶۰ کاراکتر) و عکس لینک؛ لینک و فحش در اسم/بیو قبول نمی‌شود؛ «👁 پیش‌نمایش» همان چیزی است که بقیه می‌بینند |

**چه چیزی ذخیره می‌شود**: متن/رسانه‌ی پیام ناشناس فقط برای صندوق **گیرنده** (تا خودش پاکش کند؛ حداکثر ۱۰۰۰ پیام).
شناسه‌ی فرستنده فقط برای کار کردن دکمه‌های پاسخ/بلاک/گزارش و ضداسپم نگه داشته می‌شود و به هیچ‌کس نشان داده نمی‌شود.
متن نجواها فقط تا وقتی لازم است (یک‌بار مصرف و منقضی پاک می‌شوند). مالک ربات در آمار فقط تعداد می‌بیند.

## 🔒 عضویت اجباری و پنل مالک

- هر کاربر (جز مالک) برای **ارسال** نجوا یا پیام ناشناس باید عضو همه‌ی کانال‌ها باشد. **خواندن** نجوا عضویت نمی‌خواهد.
  کسی که لینک ناشناس را باز کرده و عضو نیست، بعد از «✅ عضو شدم» مستقیم به همان لینک برمی‌گردد.
- عضو = `member`، `administrator`، `creator`، یا `restricted` با `is_member: true`. جواب «member not found» = عضو نیست.
- کانال‌های اولیه: `@HIDE_i_SEEK`، `@Nepenthw_ir`، `@wangerBots` (فقط وقتی جدول خالی باشد).
- **مالک فقط آیدی عددی `5557901897`** (روی هر دستور و هر دکمه‌ی مدیریتی بررسی می‌شود). `/admin`: کانال‌ها (حداکثر ۱۰)،
  روشن/خاموش عضویت اجباری، بن/آنبن، آمار (فقط تعداد)، **🚩 گزارش‌ها** (متن پیام گزارش‌شده بدون هویت فرستنده؛ بن،
  ۷ روز محدودیت، یا رد) و **📢 پیام سراسری** (هر نوع پیام، پیش‌نمایش و تأیید، صف در دیتابیس، ۲۵ نفر در هر دسته،
  ۴۰۳ = غیرفعال، ۴۲۹ = صبر به اندازه‌ی `retry_after`، فقط یکی در هر زمان، گزارش نهایی).

## 🚀 راه‌اندازی (یک‌بار)

در [@BotFather](https://t.me/BotFather) برای @Wanger_Shadowbot:
1. ربات ← **Serverless** ← روشن.
2. `/setinline` ← یک متن راهنما مثل `متن نجوا @username`.
3. `/setinlinefeedback` ← **Enabled**.
4. ربات را در هر سه کانال **ادمین** کنید.
5. مالک یک‌بار ربات را `/start` کند (تا پیام‌های پنل، گزارش‌ها و کارت‌ها برسد).

سپس **داخل همین پوشه**:

```bash
cd whisper_bot
npm install
npx tgcloud status             # باید Linked to app9075953171 باشد
npx tgcloud push               # ماژول‌ها + مینی‌اپ (پوشه‌ی webapp/)
npx tgcloud migrate --dry-run
npx tgcloud migrate --safe     # ۱۵ جدول
npx tgcloud webhook            # in sync، با message, inline_query, chosen_inline_result, callback_query
npm run test:cloud
```

مینی‌اپ ساخت کارت در `https://app9075953171.tgcloud.ai/` سرو می‌شود (پوشه‌ی `webapp/` بدون مرحله‌ی build؛
`tgcloud.jsonc` ← `"static": { "source": "webapp" }`) و با endpoint های `cardData` و `cardSend` حرف می‌زند.

> ⚠️ پشت پروکسی HTTPS (مثلاً نشست ابری Claude Code) CLI را با `NODE_USE_ENV_PROXY=1` اجرا کنید.
> CLI نزدیک‌ترین پوشه‌ای را که `.tgcloud/` دارد ریشه‌ی پروژه می‌داند؛ قبل از هر دستور مطمئن شوید `whisper_bot/.tgcloud/` هست.

## ✅ تست دستی در تلگرام (چیزهایی که `tgcloud run` نمی‌تواند)

با سه حساب A، B و C:
1. A و B ربات را `/start` کنند ← زبان ← (عضویت در کانال‌ها) ← دو بخش.
2. در یک گروه، A بنویسد `@Wanger_Shadowbot سلام @B` و نتیجه را بزند. C دکمه را بزند ← «این نجوا مال تو نیست 😏»،
   پیام «👀 کنجکاوها: ۱» شود و A خبر بگیرد. B دو بار باز کند ← A دو خبر بگیرد («بار ۲م»). A و B در جزئیات نجوا
   «👀 کنجکاوها» را ببینند؛ C نتواند.
3. B: «💬 پیام ناشناس» ← «👤 پروفایل» ← اسم، بیو و عکس ← «🔗 لینک من». A لینک را باز کند ← عکس با «در حال ارسال پیام
   ناشناس به (اسم B) هستی» ← دسته ← پیام. B پیام را بدون هیچ نشانی از A بگیرد؛ پاسخ بدهد؛ A جواب بدهد.
4. A امتیاز بدهد؛ C لینک را باز کند و میانگین را ببیند. B «سؤال روز» را روشن کند؛ C جواب بدهد.
5. C یک فحش بفرستد ← به B نرسد و در «🛡 فیلترشده» باشد. B «🚩 گزارش» بزند ← مالک در `/admin` ← گزارش‌ها متن را بدون
   هویت ببیند و محدود کند.
6. B: «🖼 ساخت کارت» ← مینی‌اپ ← «📩 بفرست به چت» ← عکس کارت در چت بیاید و در استوری گذاشته شود.
7. مالک: `/admin` ← پیام سراسری با یک عکس ← تأیید ← گزارش نهایی.
