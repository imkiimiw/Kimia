# 🎮 شب بازی — ربات بازی تلگرام با مینی‌اپ، فقط روی Telegram Serverless

ربات بازی چندزبانه (فارسی، انگلیسی، فرانسوی، روسی) با یک **مینی‌اپ** کامل که همه‌چیزش — کد سرور، دیتابیس،
وبهوک و فایل‌های مینی‌اپ — روی **سرورلس خود تلگرام** ([Telegram Serverless](https://core.telegram.org/bots/serverless))
اجرا می‌شود. بدون VPS و بدون سرور جدا.

## 🕹 بازی‌ها

| بازی | نفرات | توضیح |
|---|---|---|
| ❌⭕ **دوز** | ۲ | سه‌تا در یک خط. «بازی دوباره» نوبتِ شروع را عوض می‌کند و امتیاز دست‌ها را نگه می‌دارد |
| 🎲 **تخته‌نرد** | ۲ | تاس روی **سرور** ریخته می‌شود؛ همه‌ی قوانین روی سرور بررسی می‌شود: ورود از بار، بیرون بردن، جفت (۴ حرکت)، اجبار به استفاده از بیشترین تاس و در صورت امکانِ فقط یکی، تاس بزرگ‌تر. مارس ۲ و مارس مضاعف ۳ امتیاز. بازی تا ۳ یا ۵ امتیاز (سازنده‌ی اتاق انتخاب می‌کند) |
| 🃏 **حکم** | ۴ (دو تیم) | اولین آس حاکم را تعیین می‌کند؛ حاکم از ۵ کارت اول حکم را انتخاب می‌کند؛ هر دست ۷ برد؛ تیمی که اول به ۷ دور برسد برنده است. بازی از خال زمین روی سرور اجباری است. کُت = ۲ دور، کُتِ حاکم = ۳ دور. اگر صندلی‌ها بعد از ۶۰ ثانیه خالی بمانند، سازنده‌ی اتاق می‌تواند آن‌ها را با ربات پر کند |
| 🔤 **رمزواژه** | ۱ | طراحی خود این پروژه (نسخه‌ی کلمه‌ای «گاو و گوساله»): کلمه‌ی ۵ حرفی پنهان؛ هر حدس فقط می‌گوید چند حرف 🎯 درست و سر جایش و چند حرف 🔄 در کلمه ولی جای دیگر است — نه کدام. ۱۰ فرصت، **کلمه‌ی روزانه** (برای همه یکی) و **بازی آزاد**؛ کیبورد هر زبان (فارسی راست‌به‌چپ)؛ علامت‌گذاری حروف برای استنتاج. جواب تا آخر بازی فقط روی سرور است |
| 🧩 **همجوشی** | ۱ | طراحی خود این پروژه: کاشی را روی صفحه‌ی ۵×۵ بگذار؛ سه‌تا یا بیشترِ یکسانِ چسبیده به عدد بعدی ادغام می‌شوند و زنجیره می‌سازند. بازی در خود مینی‌اپ اجرا می‌شود و در پایان **حرکت‌ها** فرستاده می‌شوند؛ سرور با seed خودش بازی را دوباره اجرا می‌کند و فقط امتیاز بازسازی‌شده ثبت می‌شود (ضدتقلب) |

> رمزواژه و همجوشی به‌جای Wordle و 2048 ساخته شده‌اند (بازسازی بازی‌های تجاری موجود ساخته نمی‌شود).

**جدول رتبه:** کلی و **مخصوص هر چت** (وقتی مینی‌اپ از لینک داخل یک گروه/چت باز شود) + آمار شخصی هر بازی
(بازی، برد، باخت، مساوی، امتیاز/رکورد).

## 🧭 جریان کار

1. در هر چتی یوزرنیم ربات را تایپ کنید ← پنج بازی با تصویر و توضیح به زبان کاربر نمایش داده می‌شود.
2. انتخاب یک بازی، پیامی با دکمه‌ی «▶️ بازی» می‌فرستد که لینک **Direct Link Mini App** است:
   `https://t.me/<bot>/play?startapp=b_AbCd12345678` (حرف بازی + شناسه‌ی تصادفی اتاق؛ کمتر از ۶۴ نویسه).
3. هرکس دکمه را بزند وارد همان اتاق می‌شود؛ اولین نفرها صندلی می‌گیرند، بقیه تماشاچی‌اند. در لابی «دعوت
   دوستان» دوباره پنجره‌ی انتخاب چت را باز می‌کند.
4. وقتی بازی شروع یا تمام می‌شود، **همان پیام اینلاین ویرایش می‌شود** («در حال بازی…» / «🏆 … برد!»).
5. در پی‌وی ربات: `/start` (دکمه‌ی «🎮 بازی»، بازی با دوستان، زبان)، `/language`، `/help`، و دکمه‌ی منو.

## 🏗 معماری (کوتاه)

- **قوانین بازی‌ها** ماژول‌های خالص در `tgcloud/lib/games/` هستند که هم endpointها و هم مینی‌اپ از آن‌ها
  استفاده می‌کنند (یک نسخه از قوانین).
- **سرور مرجع است:** مینی‌اپ فقط «حرکت موردنظر» را می‌فرستد؛ سرور بررسی می‌کند و وضعیت را با **شماره‌ی نسخه**
  ذخیره می‌کند (دو حرکت هم‌زمان هر دو ثبت نمی‌شوند).
- **همگام‌سازی:** مینی‌اپ هر ~۱٫۱ ثانیه وقتی نوبت دیگری است `getState(room, since)` را صدا می‌زند (در نوبت خودت،
  لابی و بیکاری کندتر؛ وقتی مینی‌اپ پنهان است اصلاً)؛ اگر چیزی عوض نشده باشد جواب فقط `{ same: true }` است.
- **زمان‌بند ندارد:** سرورلس تلگرام cron و تایمر ندارد (مستندات رسمی)، پس همه‌چیز در درخواست بعدی بررسی می‌شود:
  تایمر نوبت (دوز و حکم ۴۵ ثانیه، تخته‌نرد ۹۰ ثانیه — با تمام شدن وقت، سرور به‌جای بازیکن حرکت می‌کند و ۳ بار
  پشت‌سرهم یعنی باخت)، حرکت ربات‌های حکم، منقضی شدن اتاق‌ها (بازی بی‌حرکت ۱۵ دقیقه بسته می‌شود؛ اتاق‌های قدیمی
  هنگام ساخت اتاق جدید پاک می‌شوند) و پیشرفت پیام همگانی.
- **عضویت اجباری** برای ربات، همه‌ی endpointها و حالت اینلاین؛ نتیجه‌ی موفق ۸ دقیقه کش می‌شود.

## 🚀 راه‌اندازی

پیش‌نیاز: Node.js ۲۲+، رباتی که در BotFather **Serverless** و **CLI Access** آن روشن است.

```bash
cd game_bot
npm install
mkdir -p .tgcloud              # مهم: وگرنه CLI ممکن است پروژه‌ی ریشه‌ی مخزن (ربات تودو) را بردارد
npx tgcloud login              # توکن: BotFather ← ربات ← Serverless ← CLI Access ← Access token
npm run deploy                 # build مینی‌اپ + push کد و فایل‌ها + migrate جدول‌ها
```

`push` آدرس مینی‌اپ را چاپ می‌کند (شبیه `https://app123456.tgcloud.ai/`). آن را در
`tgcloud/lib/config.js` در `APP_URL` بگذارید (با `/` آخر) و دوباره `npm run deploy` کنید — تصویر نتایج اینلاین
و دکمه‌ی «🎮 بازی» از این آدرس استفاده می‌کنند.

> پشت پروکسی HTTPS (مثل نشست ابری Claude Code) دستورهای CLI را با `NODE_USE_ENV_PROXY=1` اجرا کنید.
> **همیشه قبل از push، build کنید** (`npm run deploy` این کار را می‌کند)؛ push فقط پوشه‌ی `dist` را همان‌طور که هست می‌فرستد.

## ⚙️ تنظیمات BotFather (دقیقاً این‌ها)

| # | دستور | مقدار |
|---|---|---|
| 1 | `/setinline` | روشن کردن حالت اینلاین. متن راهنما (placeholder) مثلاً: `یک بازی انتخاب کن…` |
| 2 | `/setinlinefeedback` | **Enabled** (۱۰۰٪) — بدون این، ربات `inline_message_id` را نمی‌گیرد و پیام دعوت با نتیجه ویرایش نمی‌شود |
| 3 | `/newapp` | ربات را انتخاب کنید ← عنوان، توضیح، عکس ۶۴۰×۳۶۰ ← **Web App URL** = همان `APP_URL` ← **short name** = `play` (اگر اسم دیگری گذاشتید، `APP_SHORT_NAME` را در `config.js` عوض کنید) |
| 4 | `/setmenubutton` | ربات ← URL = `APP_URL` ← عنوان مثلاً `🎮 بازی` (دکمه‌ی منو در پی‌وی) |
| 5 | (اختیاری) Bot Settings ← Configure Mini App | Main Mini App را روشن کنید با همان `APP_URL` (دکمه‌ی Launch در پروفایل ربات) |
| 6 | کانال‌ها | ربات باید در `@HIDE_i_SEEK`، `@Nepenthw_ir` و `@wangerBots` **ادمین** باشد |

حالت privacy گروه مهم نیست: ربات در گروه‌ها پیامی نمی‌خواند؛ بازی گروهی از طریق اینلاین انجام می‌شود.

## 🛠 پنل مالک (فقط آیدی `5557901897`، فقط در پی‌وی)

`/admin` را بفرستید (برای هر کس دیگری هیچ جوابی داده نمی‌شود):

- **📊 آمار:** کل کاربران، فعال ۷ و ۳۰ روز، کاربرانی که ربات را بلاک کرده‌اند، تعداد بازی‌های هر بازی، اتاق‌های فعال.
- **📢 پیام همگانی:**
  1. «پیام همگانی» ← هر پیامی بفرستید (متن، عکس، ویدیو، فایل؛ با قالب‌بندی و دکمه‌ها — مثلاً یک پست را با دکمه‌هایش فوروارد کنید).
  2. پیش‌نمایش (کپی دقیق پیام) و «✅ ارسال» / «❌ لغو».
  3. با تأیید، دسته‌ی اول (۲۵ کاربر) فوراً ارسال می‌شود. ادامه: **«▶️ ارسال دسته‌ی بعدی»** یا **«📡 ارسال خودکار»**
     که صفحه‌ای از مینی‌اپ را باز می‌کند و تا وقتی باز است هر ثانیه یک دسته می‌فرستد (≈۲۵ پیام در ثانیه).
     چون سرورلس زمان‌بند ندارد، ارسال باید با یکی از این دو جلو برود؛ پیشرفت بعد از **هر پیام** در دیتابیس ذخیره
     می‌شود، پس هر وقت ادامه دهید از همان‌جا ادامه می‌دهد و به کسی دو بار نمی‌رسد. خطای 429 تلگرام هم رعایت می‌شود.
  4. کسانی که ربات را بلاک کرده‌اند علامت می‌خورند. در پایان گزارش: ارسال‌شده / ناموفق / بلاک‌کرده. «⏹ توقف» ارسال در جریان را لغو می‌کند.
- **🔒 کانال‌ها:** فهرست (✅ ربات ادمین است / ⚠️ نیست)، افزودن با `@username`، لینک `t.me/…`، آیدی عددی
  (`-100…`) یا **فوروارد یک پست از کانال** — ربات اول بررسی می‌کند که در آن کانال ادمین است؛ حداکثر **۱۰ کانال**
  (یازدهمی رد می‌شود)؛ حذف با تأیید؛ روشن/خاموش کردن کل عضویت اجباری. اگر بررسی یک کانال خطا بدهد، آن کانال
  نادیده گرفته می‌شود تا کسی قفل نشود و به مالک (حداکثر هر ۳ ساعت یک‌بار) هشدار داده می‌شود.

## 🧪 تست

| دستور | چه می‌کند |
|---|---|
| `npm test` | بررسی ایستای قوانین پلتفرم (import ها، globals ممنوع در V8، کامنت `//`، …) + **۲۳ تست قوانین** (از جمله ۳۰۰ مسابقه‌ی تصادفی تخته‌نرد و ۳۰۰ مسابقه‌ی حکم با هوش مصنوعی، بار، بیرون بردن، جفت، قانون تاس بزرگ‌تر، بازی از خال، کُت) + **۱۷ سناریوی سرور** روی شبیه‌ساز sdk و Bot API ساختگی (عضویت اجباری و کش، اینلاین، هر پنج بازی، تایمر و باخت با غیبت، رتبه‌ها، پنل مالک، پیام همگانی با 429 و ادامه) |
| `npm run test:ui` | مینی‌اپِ build‌شده در Chromium با **چند حساب شبیه‌سازی‌شده** که از طریق رابط کاربری واقعی با هم بازی می‌کنند (دوز، تخته‌نرد، حکم، رمزواژه، همجوشی، تنظیمات، صفحه‌ی عضویت)؛ اسکرین‌شات‌ها در `test/output/` |

### تست دستی در تلگرام (با دو حساب)

1. حساب ۱: در یک چت با حساب ۲ یوزرنیم ربات را تایپ کنید ← «تخته‌نرد» را بفرستید ← «▶️ بازی».
2. حساب ۲: همان دکمه را بزند ← بازی شروع می‌شود؛ پیام اینلاین «در حال بازی» می‌شود.
3. چند نوبت بازی کنید؛ یک حساب را ۹۰ ثانیه بی‌حرکت بگذارید تا حرکت خودکار را ببینید.
4. با یک حساب سوم که عضو کانال‌ها نیست: اینلاین هیچ بازی‌ای نشان نمی‌دهد و دکمه‌ی عضویت می‌آید.
5. `/admin` ← پیام همگانی کوتاه به خودتان و یک حساب دیگر.

## ➕ افزودن یک بازی جدید

1. **قوانین:** `tgcloud/lib/games/<name>.js` — خالص، بدون `sdk`؛ برای بازی چندنفره همان رابط:
   `SEATS, TURN_SEC, create(opts, rng), turn(state), act(state, seat, action, rng) → { state } | { error },
   auto(state, seat, rng), outcome(state), rematch(state, rng), view(state, seat)` و رویدادها با `logEvent`.
2. **ثبت:** در `tgcloud/lib/rooms.js` به `MODS` اضافه کنید؛ در `tgcloud/lib/config.js` به `GAMES` / `ROOM_GAMES` و یک
   حرف در `PAYLOAD_LETTER`؛ در `tgcloud/lib/inline.js` به `ORDER` و `SEATS`.
3. **متن‌ها:** `game_<name>` و `desc_<name>` و متن‌های خود بازی را در هر چهار فایل `tgcloud/lib/i18n/*.js` بگذارید.
4. **رابط:** `app/games/<Name>.tsx` (props: `room`, `move`, `busy`) و ثبت در `BOARDS` در `app/screens/Room.tsx`؛
   تصویر SVG در `app/art.js` و `npm run thumbs`.
5. **تست:** تست‌های قوانین در `test/unit/` و یک سناریو در `test/e2e.mjs`؛ بعد `npm test` و `npm run deploy`.
