بدون سرور، بدون هزینه (پلن رایگان کلادفلر کافی است) و همیشه روشن.

## 🔒 جوین اجباری و پنل مالک

- کاربر تا عضو **همه** کانال‌های تنظیم‌شده نشود نمی‌تواند از ربات استفاده کند (دکمه‌ی عضویت برای هر کانال + دکمه «✅ عضو شدم»). اگر کاربر از کانالی خارج شود، دوباره قفل می‌شود.
- کانال‌های اولیه (فقط بار اول به‌صورت خودکار ثبت می‌شوند):
  - https://t.me/HIDE_i_SEEK
  - https://t.me/Nepenthw_ir
  - https://t.me/wangerBots
- **فقط مالک** با آیدی عددی `5557901897` در پی‌وی ربات می‌تواند کانال‌ها را اضافه/حذف کند. **سقف: ۱۰ کانال.**
- مالک خودش نیاز به جوین ندارد و دکمه «👑 پنل مدیریت» را در منو می‌بیند.

**پنل مالک** (دکمه 👑 یا `/admin`):
- 📢 لیست کانال‌ها، ➕ افزودن، ❌ حذف (با تأیید)، 🔄 بررسی وضعیت (آیا ربات در کانال ادمین است)
- 📊 آمار ربات (کاربران، فعال‌ها، بلاک‌کرده‌ها، کارها)
- 📣 پیام همگانی (متن، عکس، ویدیو، فایل یا فوروارد؛ در پس‌زمینه ارسال و در پایان گزارش داده می‌شود)

**دستورات متنی مالک:**

```
/channels                                  لیست کانال‌ها
/addchannel @username                      افزودن کانال عمومی
/addchannel https://t.me/username          افزودن با لینک
/addchannel -1001234567890 https://t.me/+AbCdEf   کانال خصوصی (آیدی عددی + لینک دعوت)
/delchannel @username   یا   /delchannel 2  حذف (با یوزرنیم یا شماره در لیست)
```

برای افزودن می‌توانید یک پست از کانال را هم بعد از زدن «➕ افزودن کانال» فوروارد کنید.

> ⚠️ **مهم:** ربات باید در هر کانال **ادمین** باشد، وگرنه تلگرام اجازه‌ی بررسی عضویت را نمی‌دهد. کانالی که ربات در آن ادمین نیست بررسی نمی‌شود (کاربران به‌خاطر آن قفل نمی‌شوند) و در «🔄 بررسی وضعیت» با ⚠️ نشان داده می‌شود.

## 🚀 راه‌اندازی (حدود ۵ دقیقه)

پیش‌نیاز: یک حساب رایگان [Cloudflare](https://dash.cloudflare.com/sign-up) و Node.js نسخه ۱۸ به بالا.

1. **ساخت ربات:** در [@BotFather](https://t.me/BotFather) دستور `/newbot` را بزنید و توکن را بردارید.
2. **ادمین کردن ربات** در سه کانال `@HIDE_i_SEEK`، `@Nepenthw_ir` و `@wangerBots` (دسترسی خاصی لازم نیست، فقط ادمین باشد).
3. **نصب و دیپلوی:**

   ```bash
   npm install
   npx wrangler login
   npx wrangler deploy
   ```

   دیتابیس D1 در اولین دیپلوی خودکار ساخته می‌شود. آدرس ورکر چاپ می‌شود، مثلاً `https://todo-bot.<your-subdomain>.workers.dev`

4. **ثبت سکرت‌ها:**

   ```bash
   npx wrangler secret put BOT_TOKEN        # توکن BotFather
   npx wrangler secret put WEBHOOK_SECRET   # یک رمز تصادفی، فقط حروف انگلیسی، عدد، _ و -
   ```

5. **یک بار** از اکانت مالک ربات را `/start` کنید، بعد این آدرس را در مرورگر باز کنید تا وبهوک و منوی دستورات تنظیم شود:

   ```
   https://todo-bot.<your-subdomain>.workers.dev/setup?secret=<WEBHOOK_SECRET>
   ```

   باید `"ok": true` ببینید. تمام! 🎉

### راه‌اندازی فقط با داشبورد Cloudflare (کپی/پیست، بدون CLI)

1. **D1:** Storage & Databases ← D1 SQL Database ← Create Database (نام: `todo-bot-db`، Location: Automatic).
2. **ورکر:** Workers & Pages ← Create application ← Start with Hello World! ← نام `todo-bot` ← Deploy.
3. **کد:** Edit code ← یکی از دو روش، بعد دکمه‌ی **Deploy** (نه Save):
   - **یک فایل:** محتوای [`dist/worker.js`](dist/worker.js) را به‌جای کل کد `worker.js` بچسبانید.
   - **فایل‌به‌فایل:** محتوای `src/index.js` را در `worker.js` بچسبانید و ۱۰ فایل دیگر `src/` را با همان اسم‌ها کنار آن بسازید (New File…).
4. **Binding:** Settings ← Bindings ← Add binding ← D1 database ← Variable name: `DB` ← `todo-bot-db`.
5. **Secrets:** Settings ← Variables and Secrets ← Add ← Type: Secret ← `BOT_TOKEN` و `WEBHOOK_SECRET` ← Deploy.
6. **Cron:** Settings ← Trigger Events ← Add ← Cron Triggers ← `* * * * *` (شروع تا ۱۵ دقیقه).
7. ربات را از اکانت مالک `/start` کنید و `https://<آدرس-ورکر>/setup?secret=<WEBHOOK_SECRET>` را باز کنید.
8. **بررسی:** آدرس خود ورکر (`https://<آدرس-ورکر>/`) یک چک‌لیست ✅/❌ از همه‌ی مراحل نشان می‌دهد.

> `dist/worker.js` با `npm run build` از `src/` ساخته می‌شود؛ بعد از تغییر کد دوباره بسازید.

### دیپلوی از طریق GitHub (بدون نیاز به کامپیوتر)

در تنظیمات مخزن ← Secrets and variables ← Actions این چهار سکرت را بسازید:
`CLOUDFLARE_API_TOKEN` (با قالب «Edit Cloudflare Workers» در داشبورد کلادفلر + دسترسی D1 Edit)، `CLOUDFLARE_ACCOUNT_ID`، `BOT_TOKEN`، `WEBHOOK_SECRET`.
بعد از تب Actions، ورک‌فلوی **Deploy to Cloudflare** را اجرا کنید و در پایان قدم ۵ بالا را انجام دهید.

## 🏗 ساختار پروژه

```
src/
  index.js      ورودی ورکر: /webhook، /setup و Cron
  bot.js        پیام‌ها، دکمه‌ها و قابلیت‌های تودو
  admin.js      پنل مالک: کانال‌ها، آمار، پیام همگانی
  join.js       بررسی جوین اجباری
  cron.js       یادآورها، خلاصه روزانه، ارسال همگانی
  db.js         جدول‌ها و کوئری‌های D1 (جدول‌ها خودکار ساخته می‌شوند)
  time.js       تقویم شمسی، منطقه زمانی و تشخیص تاریخ فارسی
  quickadd.js   سینتکس افزودن سریع
  ui.js         متن‌ها و کیبوردها
  telegram.js   ارتباط با Bot API
dist/worker.js  کل ربات در یک فایل (برای چسباندن در داشبورد؛ npm run build)
test/           تست واحد + تست سرتاسری با شبیه‌ساز تلگرام
```

**محدودیت‌های پلن رایگان کلادفلر:** ۱۰۰ هزار درخواست در روز، D1 با ۵ میلیون خواندن و ۱۰۰ هزار نوشتن در روز — برای هزاران کاربر کافی است. در هر دقیقه حداکثر ۲۰ یادآور، ۱۰ خلاصه روزانه و ۱۵ پیام همگانی ارسال می‌شود (سقف ۵۰ درخواست خروجی پلن رایگان).
