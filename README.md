# 🤖 ربات تودو لیست تلگرام — فقط روی Telegram Serverless

ربات مدیریت کارها (فارسی) با **عضویت اجباری** که فقط روی **سرورلس خود تلگرام**
([Telegram Serverless](https://core.telegram.org/bots/serverless)) اجرا می‌شود؛ کد، دیتابیس و وبهوک
همه داخل تلگرام است. بدون VPS، Vercel، Cloudflare، AWS یا GitHub Actions.

## ✨ ۱۰ قابلیت

| # | قابلیت | نحوه‌ی استفاده |
|---|---|---|
| 1 | ➕ افزودن کار | هر متنی بفرستید، یا `/add متن` (حداکثر ۵۰۰ کاراکتر، سقف ۵۰۰ کار برای هر کاربر) |
| 2 | 📋 لیست کارها | `/list` — صفحه‌بندی ۸تایی با دکمه‌های «قبلی / بعدی» |
| 3 | ✅ انجام‌شده / انجام‌نشده | دکمه‌ی ⬜️/✅ کنار هر کار در لیست، یا داخل صفحه‌ی کار |
| 4 | ✏️ ویرایش متن | صفحه‌ی کار ← «✏️ ویرایش متن» |
| 5 | 🗑 حذف | صفحه‌ی کار ← «🗑 حذف» ← تأیید |
| 6 | 🔥 اولویت | 🔴 بالا / 🟡 متوسط / 🟢 پایین؛ مرتب‌سازی بر اساس اولویت، تاریخ یا جدیدترین |
| 7 | 📅 سررسید | `1405/08/10` (شمسی) یا `2026-11-01` (میلادی) یا دکمه‌های امروز/فردا/هفته بعد؛ کار عقب‌افتاده هنگام باز کردن لیست ⏰ می‌گیرد |
| 8 | 🗂 دسته‌بندی | `/cats` — ساخت دسته و فیلتر لیست بر اساس دسته |
| 9 | 🔍 جستجو | `/search نان` |
| 10 | 📊 آمار و پاک‌سازی | `/stats` — کل، انجام‌شده، باز، عقب‌افتاده + «پاک‌کردن کارهای انجام‌شده» با تأیید |

> سرورلس تلگرام زمان‌بند (cron) ندارد، پس ربات **یادآور خودکار نمی‌فرستد**؛ سررسیدها هر بار که لیست باز می‌شود بررسی می‌شوند.

## 🔒 عضویت اجباری و پنل مالک

- هر کاربر (جز مالک) قبل از استفاده باید عضو **همه‌ی** کانال‌ها باشد. پیام قفل فقط کانال‌هایی را که هنوز عضو
  نشده با دکمه‌ی لینک نشان می‌دهد، به‌همراه دکمه‌ی «✅ عضو شدم».
- عضو = `member`، `administrator`، `creator`، یا `restricted` با `is_member: true`. `left` و `kicked` عضو نیستند.
- کانال‌های اولیه در اولین اجرا (فقط اگر جدول خالی باشد و قبلاً پر نشده باشد) ثبت می‌شوند:
  `@HIDE_i_SEEK`، `@Nepenthw_ir`، `@wangerBots`.
- اگر بررسی یک کانال خطا بدهد (مثلاً ربات ادمین نیست)، آن کانال برای کاربران نادیده گرفته می‌شود تا همه قفل نشوند،
  و به مالک حداکثر هر ۳ ساعت یک‌بار هشدار داده می‌شود.
- **مالک فقط آیدی عددی `5557901897`** است (یوزرنیم هیچ‌جا بررسی نمی‌شود). `/admin` فقط برای مالک و فقط در پی‌وی:
  لیست کانال‌ها با وضعیت ادمین بودن ربات، افزودن (یوزرنیم یا لینک t.me؛ با `getChat` و `getChatMember` بررسی
  می‌شود که کانال وجود دارد و ربات ادمین است)، حذف با تأیید، سقف **۱۰ کانال**، و خاموش/روشن کردن عضویت اجباری.

## 🚀 راه‌اندازی

پیش‌نیاز در تلگرام:
1. [@BotFather](https://t.me/BotFather) ← ربات ← **Serverless** ← روشن.
2. ربات را در هر سه کانال **ادمین** کنید (بدون ادمین بودن، تلگرام اجازه‌ی بررسی عضویت نمی‌دهد).

با Node.js ۱۸ به بالا:

```bash
npm install
npx tgcloud login              # توکن: BotFather ← ربات ← Serverless ← CLI Access ← Access token
npx tgcloud status && npx tgcloud diff
npx tgcloud push               # آپلود کد
npx tgcloud migrate --dry-run  # دیدن تغییرات دیتابیس
npx tgcloud migrate --safe     # ساخت ۶ جدول: users, tasks, categories, channels, settings, user_state
npx tgcloud webhook            # باید in sync باشد؛ وگرنه: npx tgcloud webhook sync
```

(در محیط CI یا ابری به‌جای `login` متغیر `TGCLOUD_TOKEN` را تنظیم کنید.)

## 🧪 تست

```bash
npm test                  # تست واحد + ۴۲ سناریوی سرتاسری روی شبیه‌ساز محلی sdk
npm run test:cloud        # همه‌ی سناریوها روی خود Telegram Serverless با `npx tgcloud run`
npm run test:cloud:local  # بررسی خود اسکریپت تست ابری روی شبیه‌ساز (بدون توکن)
```

`test:cloud` روی دیتابیس واقعی ربات اجرا می‌شود ولی فقط با کاربران آزمایشی (آیدی‌های `990000001` تا `990000003`)
کار می‌کند و در پایان همه چیز را برمی‌گرداند (کاربران آزمایشی، کانال‌های ساختگی، کانال حذف‌شده، وضعیت عضویت اجباری).
سناریوهای مالک با آیدی واقعی مالک اجرا می‌شوند، پس صفحه‌هایشان در تلگرام مالک هم دیده می‌شود.
خروجی خام هر اجرا در `test/cloud/output/run.log` و خلاصه در `test/cloud/output/summary.md` ذخیره می‌شود.

```
tgcloud/
  schema.js                  جدول‌ها (بدون کلید خارجی؛ همه‌ی کوئری‌ها با user_id و ایندکس)
  handlers/message.js        پیام‌ها
  handlers/callback_query.js دکمه‌های شیشه‌ای (هر دکمه answerCallbackQuery می‌گیرد)
  lib/
    router.js   ترتیب بررسی‌ها و جدول کدهای callback_data
    todo.js     ۱۰ قابلیت تودو
    admin.js    پنل مالک
    join.js     عضویت اجباری
    store.js    همه‌ی کوئری‌های دیتابیس
    tg.js       فراخوانی Bot API + ردگیری (trace) برای خروجی tgcloud run
    ui.js       متن‌ها و کیبوردهای مشترک
    dates.js    تقویم شمسی و تشخیص تاریخ
    text.js     ارقام فارسی، escape، نرمال‌سازی
    config.js   مالک، کانال‌های اولیه و سقف‌ها
test/
  unit.mjs, e2e.mjs          تست‌های محلی (test/sdk = شبیه‌ساز sdk، mock-telegram.mjs = شبیه‌ساز Bot API)
  cloud/run-tests.mjs        تست روی خود سرورلس تلگرام
  cloud/devtools.js          endpoint کمکی فقط برای مدت اجرای تست (هرگز push نمی‌شود)
```
