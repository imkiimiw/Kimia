# 🤖 ربات تودو لیست تلگرام روی Telegram Serverless

ربات مدیریت کارها با **جوین اجباری** که روی **سرورلس خود تلگرام** ([Telegram Serverless](https://core.telegram.org/bots/serverless)) اجرا می‌شود.
بدون سرور، بدون هاست و بدون Cloudflare: کد، دیتابیس و وبهوک همه داخل خود تلگرام است.

## ✨ ۱۰ قابلیت ربات

| # | قابلیت | توضیح |
|---|---|---|
| 1 | ⚡ افزودن سریع هوشمند | هر متنی بفرستید کار می‌شود؛ `#دسته`، `!1/!2/!3` (اولویت) و `@زمان` (ددلاین) را از خود متن تشخیص می‌دهد. نمونه: `خرید نان #خانه !1 @فردا 18:00` |
| 2 | 🔥 اولویت‌بندی | سه سطح 🔴🟡🟢؛ لیست به‌صورت خودکار بر اساس اولویت و ددلاین مرتب می‌شود |
| 3 | 📅 ددلاین با تقویم شمسی | `فردا`، `شنبه`، `1405/08/10`، `+3`، `2026-11-01 09:00` و… با هشدار ⚠️ برای کارهای عقب‌افتاده |
| 4 | ⏰ یادآور زمان‌دار | پیام یادآوری با دکمه‌های «انجام شد» و «تعویق ۱۰ دقیقه / ۱ ساعت» (نحوه‌ی ارسال: پایین‌تر) |
| 5 | 🗂 دسته‌بندی | گروه‌بندی کارها و مشاهده‌ی هر دسته به‌صورت جدا (نیم‌فاصله هم پشتیبانی می‌شود) |
| 6 | 🔁 کارهای تکراری | روزانه / هفتگی / ماهانه (ماه شمسی)؛ با انجام هر نوبت، نوبت بعد خودکار تنظیم و سابقه ثبت می‌شود |
| 7 | 📝 یادداشت و ویرایش کامل | ویرایش متن، یادداشت، اولویت، دسته، ددلاین، یادآور و تکرار هر کار از کارت آن |

| 10 | 🌅 خلاصه روزانه | هر روز از ساعت دلخواه، کارهای امروز و عقب‌افتاده ارسال می‌شود |

به‌علاوه: 📤 خروجی فایل متنی از همه کارها، 🧹 پاکسازی کارهای انجام‌شده، صفحه‌بندی لیست، نمای «📅 امروز».

## 🔒 جوین اجباری و پنل مالک

- کاربر تا عضو **همه** کانال‌های تنظیم‌شده نشود نمی‌تواند از ربات استفاده کند (دکمه‌ی عضویت برای هر کانال + دکمه «✅ عضو شدم»). اگر از کانالی خارج شود، دوباره قفل می‌شود.
- کانال‌های اولیه (با اولین پیامی که به ربات می‌رسد، یک بار ثبت می‌شوند):
  - https://t.me/HIDE_i_SEEK
  - https://t.me/Nepenthw_ir
  - https://t.me/wangerBots
- **فقط مالک** با آیدی عددی `5557901897` در پی‌وی ربات می‌تواند کانال‌ها را اضافه/حذف کند. **سقف: ۱۰ کانال.**
- مالک خودش نیاز به جوین ندارد و دکمه «👑 پنل مدیریت» را در منو می‌بیند.

**پنل مالک** (دکمه 👑 یا `/admin`):
- 📢 لیست کانال‌ها، ➕ افزودن، ❌ حذف (با تأیید)، 🔄 بررسی وضعیت (آیا ربات در کانال ادمین است)
- 📊 آمار ربات + 🩺 وضعیت سرورلس (خطاهای تحویل پیام، آخرین پردازش یادآورها)
- 📣 پیام همگانی (متن، عکس، ویدیو، فایل یا فوروارد؛ آلبوم نه)

**دستورات متنی مالک:**

```
/channels                                  لیست کانال‌ها
/addchannel @username                      افزودن کانال عمومی
/addchannel https://t.me/username          افزودن با لینک
/addchannel -1001234567890 https://t.me/+AbCdEf   کانال خصوصی (آیدی عددی + لینک دعوت)
/delchannel @username   یا   /delchannel 2  حذف (با یوزرنیم یا شماره در لیست)
```

> ⚠️ **مهم:** ربات باید در هر کانال **ادمین** باشد، وگرنه تلگرام اجازه‌ی بررسی عضویت را نمی‌دهد. کانالی که ربات در آن ادمین نیست بررسی نمی‌شود (کاربران به‌خاطر آن قفل نمی‌شوند) و در «🔄 بررسی وضعیت» با ⚠️ نشان داده می‌شود.

## ⏰ یادآورها بدون زمان‌بند

Telegram Serverless (تا نسخه‌ی فعلی، مهر ۱۴۰۵) **کرون یا زمان‌بند ندارد**؛ کد فقط وقتی اجرا می‌شود که پیامی یا دکمه‌ای به ربات برسد.
برای همین یادآورها، خلاصه‌های روزانه و پیام همگانی همراه با **هر پیام یا دکمه‌ای که از هر کاربری به ربات می‌رسد** پردازش می‌شوند (حداکثر دقیقه‌ای یک‌بار):

- ربات شلوغ: یادآورها تقریباً سر وقت می‌رسند.
- ربات خلوت (مثلاً نیمه‌شب): یادآور با اولین فعالیت بعد از زمانش ارسال می‌شود.
- پیام همگانی: دسته‌ی اول بلافاصله بعد از تأیید ارسال می‌شود؛ بقیه با فعالیت ربات یا دکمه‌ی «▶️ ارسال دسته‌ی بعدی».

اگر تلگرام زمان‌بند اضافه کند، فقط کافی است `maybeTick` در `tgcloud/lib/tick.js` از آن صدا زده شود.

## 🚀 راه‌اندازی

پیش‌نیاز در تلگرام:
1. ربات را در [@BotFather](https://t.me/BotFather) بسازید (یا ربات موجود را انتخاب کنید).
2. در BotFather: ربات ← **Serverless** ← روشن کنید.
3. ربات را در هر سه کانال `@HIDE_i_SEEK`، `@Nepenthw_ir` و `@wangerBots` **ادمین** کنید.

### روش ۱: با CLI رسمی تلگرام (پیشنهادی)

نیاز به Node.js نسخه ۱۸ به بالا دارد:

```bash
npm install
npx tgcloud login     # توکن: BotFather ← ربات ← Serverless ← CLI Access ← Access token
npx tgcloud push      # آپلود کد
npx tgcloud migrate   # ساخت ۵ جدول دیتابیس (تأیید کنید)
```

بعد از اکانت مالک به ربات `/start` بدهید. تمام!

### روش ۲: فقط با BotFather روی گوشی

در BotFather ← ربات ← Serverless:
1. **Database**: محتوای `tgcloud/schema.js` را بچسبانید، تغییرات را تأیید و اعمال کنید.
2. **Library**: برای هر فایل `tgcloud/lib/` یک ماژول با همان اسم بسازید و محتوایش را بچسبانید:
   `config`، `utf8`، `time`، `ui`، `quickadd`، `d1`، `store`، `telegram`، `join`، `tick`، `admin`، `bot`
3. **Handlers**: دو هندلر `message` و `callback_query` بسازید و محتوای `tgcloud/handlers/message.js` و `tgcloud/handlers/callback_query.js` را بچسبانید.

> اسم برچسب‌ها در BotFather از مستندات تلگرام است و ممکن است کمی فرق داشته باشد. پروژه یکی است: هر وقت به کامپیوتر رسیدید `npx tgcloud pull` همان را می‌آورد.

### به‌روزرسانی بعدی

- تغییر کد: `npx tgcloud push`
- تغییر `schema.js`: بعد از push، `npx tgcloud migrate`
- اجرای یک هندلر روی سرورلس بدون دیپلوی: `npx tgcloud run handlers/message '{ chat: { id: 1, type: "private" }, from: { id: 1, first_name: "Test" }, text: "/help" }'`

## 🧪 تست

```bash
npm test
```

- **تست واحد:** تقویم شمسی، تشخیص تاریخ/ساعت فارسی، سینتکس افزودن سریع، ورودی کانال‌ها، UTF-8.
- **تست سرتاسری (۵۴ سناریو):** همان هندلرهای `tgcloud/handlers` با یک شبیه‌ساز محلی از `sdk` تلگرام (`test/sdk/`: دیتابیس SQLite + کلاینت Bot API) و یک شبیه‌ساز API تلگرام اجرا می‌شوند. سراسری‌های غیراستاندارد (`fetch`، `TextEncoder`، `setTimeout`، …) قبل از اجرا حذف می‌شوند تا مثل ایزوله‌ی V8 تلگرام فقط امکانات خود جاوااسکریپت در دسترس باشد. همه‌ی مسیرها پوشش داده می‌شوند: جوین اجباری، ۱۰ قابلیت، یادآور و خلاصه روزانه از طریق «تیک»، مدیریت کانال‌ها و سقف ۱۰ تایی، دسترسی فقط مالک، پیام همگانی و…

## 🏗 ساختار پروژه

```
tgcloud/
  schema.js                 جدول‌های دیتابیس (با tgcloud migrate ساخته می‌شوند)
  handlers/message.js       هر پیام
  handlers/callback_query.js هر دکمه‌ی شیشه‌ای
  lib/
    bot.js        پیام‌ها، دکمه‌ها و قابلیت‌های تودو
    admin.js      پنل مالک: کانال‌ها، آمار، پیام همگانی
    join.js       بررسی جوین اجباری
    tick.js       یادآورها، خلاصه روزانه، پیام همگانی (جای کرون)
    store.js      کوئری‌های دیتابیس
    d1.js         لایه‌ی کوچک روی db.run/all/get سرورلس
    telegram.js   ارتباط با Bot API از طریق sdk
    time.js       تقویم شمسی، منطقه زمانی و تشخیص تاریخ فارسی
    quickadd.js   سینتکس افزودن سریع
    ui.js         متن‌ها و کیبوردها
    utf8.js       شمارش بایت UTF-8 (ایزوله TextEncoder ندارد)
    config.js     مالک، کانال‌های اولیه، سقف ۱۰ کانال، منطقه‌ی زمانی
test/             تست واحد + تست سرتاسری + شبیه‌ساز sdk و API
tgcloud.jsonc     تنظیمات پروژه‌ی tgcloud
```

**نکته‌ها:** تلگرام هنوز سقف CPU، زمان اجرا یا قیمت این سرویس را منتشر نکرده و خروجی گرفتن از دیتابیس مستند نشده است. هر نوبت پردازش یادآورها محدود است (حداکثر ۱۰ یادآور، ۵ خلاصه و ۱۵ پیام همگانی) تا هیچ پیامی کار سنگینی انجام ندهد.
