# راهنمای مدیر — Wanger Stickers (فاز ۱)

این راهنما برای کیمی است: کارهایی که قبل و بعد از راه‌اندازی باید انجام شود و بخش‌های پنل مدیریت.
ربات: **@Wanger_Motionbot** · Mini App: `https://app9292593567.tgcloud.ai/`

## قبل از راه‌اندازی (یک بار)

1. **ربات را در سه کانال عضویت اجباری ادمین کن**: @HIDE_i_SEEK، @Nepenthw_ir و @wangerBots.
   اندازه‌گیری امروز نشان داد @Wanger_Motionbot هنوز در هیچ‌کدام ادمین نیست. تا وقتی ادمین نباشد، تلگرام
   اجازه‌ی بررسی عضویت نمی‌دهد و ربات آن کانال را نادیده می‌گیرد (و به تو هشدار می‌دهد).
2. **کانال انتشار جدید را بساز** و ربات را آن‌جا ادمین کن با اجازه‌ی «ارسال پیام» و ترجیحاً «حذف پیام».
3. بعد از راه‌اندازی، در ربات: `/admin` ← «📢 کانال انتشار» ← «➕ تعیین کانال» و یوزرنیم کانال را بفرست
   (یا یک پست از کانال را فوروارد کن).

## انتشار پک در کانال (درخواست تو)

1. کاربر در «پک‌های من» ← پک ← «📢 انتشار در کانال» را می‌زند (پک باید دست‌کم ۳ استیکر داشته باشد — قابل تغییر).
2. پیش‌نمایش پست را می‌بیند و **خودش انتخاب می‌کند** اسم و آیدی‌اش نمایش داده شود یا نه (پیش‌فرض: هیچ‌کدام).
3. درخواست برای تو و همه‌ی **بررسی‌کننده‌ها** فرستاده می‌شود: «✅ تأیید و انتشار»، «❌ رد» (با دلیل یا بدون دلیل)،
   «🚫 رد و محروم از انتشار» (فقط خودت)، و «👁 دیدن پک».
4. بعد از تأیید، ربات اولین استیکر پک را با دکمه‌های «➕ افزودن»، (اسم/آیدی سازنده اگر خواسته بود) و
   «🎨 پک خودت را بساز» در کانال می‌گذارد و به سازنده لینک پست را می‌دهد.
5. بین دو پست دست‌کم ۳۰ ثانیه فاصله است (قابل تغییر)؛ بقیه در صف می‌مانند و با فعالیت بعدی ربات منتشر می‌شوند
   (یا «🚀 انتشار بعدی همین حالا» در صف).
6. سازنده هر وقت بخواهد پک را برمی‌دارد؛ تو یا بررسی‌کننده‌ها هم «🗑 حذف از کانال» دارید. تلگرام فقط پست‌های
   کمتر از ۴۸ ساعت را پاک می‌کند؛ پست قدیمی‌تر فقط دکمه‌هایش برداشته می‌شود.

**بررسی‌کننده‌ها**: «📢 کانال انتشار» ← «👮 بررسی‌کننده‌ها» ← «➕ افزودن» و آیدی عددی، @یوزرنیم یا یک
پیام فورواردی از او. باید قبلاً ربات را استارت کرده باشد. بررسی‌کننده با `/admin` فقط «📋 صف انتشار» را می‌بیند
و به بقیه‌ی پنل دسترسی ندارد.

## راه‌اندازی و به‌روزرسانی (برای اجرای Claude یا خودت)

```bash
cd wanger-stickers
npm install
npm test                               # همه‌ی تست‌ها باید سبز باشند
npm run tg -- migrate --local --dry-run   # دیدن تغییرات دیتابیس (چیزی اعمال نمی‌شود)
npm run tg -- migrate --local --safe      # ساخت جدول‌ها (فقط با تأیید تو)
npm run deploy                            # build + push (فقط با تأیید تو)
```
