# راهنمای مدیر — Wanger Stickers (فاز ۱ تا ۳)

این راهنما برای کیمی است: کارهایی که قبل و بعد از راه‌اندازی باید انجام شود و بخش‌های پنل مدیریت.
ربات: **@Wanger_Motionbot** · Mini App: `https://app9292593567.tgcloud.ai/`

## قبل از راه‌اندازی (یک بار)

1. **ربات را در سه کانال عضویت اجباری ادمین کن**: @HIDE_i_SEEK، @Nepenthw_ir و @wangerBots.
   اندازه‌گیری امروز نشان داد @Wanger_Motionbot هنوز در هیچ‌کدام ادمین نیست. تا وقتی ادمین نباشد، تلگرام
   اجازه‌ی بررسی عضویت نمی‌دهد و ربات آن کانال را نادیده می‌گیرد (و به تو هشدار می‌دهد).
2. **کانال انتشار جدید را بساز** و ربات را آن‌جا ادمین کن با اجازه‌ی «ارسال پیام» و ترجیحاً «حذف پیام».
3. بعد از راه‌اندازی، در ربات: `/admin` ← «📢 کانال انتشار» ← «➕ تعیین کانال» و یوزرنیم کانال را بفرست
   (یا یک پست از کانال را فوروارد کن).
4. **کانال ذخیره را بساز (برای پک‌های واتس‌اپ، فاز ۳)**: یک کانال **خصوصی** جدید، ربات را آن‌جا ادمین کن با
   اجازه‌ی «ارسال پیام»، بعد `/admin` ← ⚙️ تنظیمات ← «🗄 کانال ذخیره» و آیدی عددی یا یوزرنیم را بفرست.
   تا وقتی این کار انجام نشده، فایل‌های پک واتس‌اپ هر کاربر بی‌صدا در چت خودش با ربات نگه داشته می‌شود
   (کار می‌کند، ولی چت کاربر شلوغ‌تر می‌شود) و ربات روزی یک بار یادآوری‌اش را برایت می‌فرستد.

| 📣 پیام همگانی | هر پیامی را بفرست یا فوروارد کن ← پیش‌نمایش ← مخاطب (همه، فارسی، انگلیسی، فعال ۳۰ روز، Pro) ← روش (کپی یا فوروارد) ← ارسال. توقف موقت، ادامه و لغو. هیچ‌کس پیام را دو بار نمی‌گیرد. |
| 🔒 عضویت اجباری | فهرست با وضعیت (✅ سالم، ⚠️ ربات ادمین نیست، ❌ پیدا نشد)، افزودن (یوزرنیم، آیدی، لینک یا پست فورواردی؛ حداکثر ۱۰)، بالا/پایین، فعال/غیرفعال، لینک دعوت، حذف، خاموش/روشن کل عضویت، پیش‌نمایش |

| 📢 کانال انتشار | تعیین/تغییر/بررسی کانال، روشن/خاموش انتشار، **بررسی‌کننده‌ها**، صف انتشار |

| 💾 پشتیبان | کاربران، پک‌ها، انتشارها و تنظیمات به‌صورت فایل JSON |

## انتشار پک در کانال (درخواست تو)

1. کاربر در «پک‌های من» ← پک ← «📢 انتشار در کانال» را می‌زند (پک باید دست‌کم ۳ استیکر داشته باشد — قابل تغییر).
2. پیش‌نمایش پست را می‌بیند و **خودش انتخاب می‌کند** اسم و آیدی‌اش نمایش داده شود یا نه (پیش‌فرض: هیچ‌کدام).
3. درخواست برای تو و همه‌ی **بررسی‌کننده‌ها** فرستاده می‌شود: «✅ تأیید و انتشار»، «❌ رد» (با دلیل یا بدون دلیل)،
   «🚫 رد و محروم از انتشار» (فقط خودت)، و «👁 دیدن پک».
4. بعد از تأیید، ربات اولین استیکر پک را با دکمه‌های «➕ افزودن»، (اسم/آیدی سازنده اگر خواسته بود) و
   «🎨 پک خودت را بساز» در کانال می‌گذارد و به سازنده لینک پست را می‌دهد.
5. بین دو پست دست‌کم ۳۰ ثانیه فاصله است (قابل تغییر)؛ بقیه در صف می‌مانند و با فعالیت بعدی ربات منتشر می‌شوند
   (یا «🚀 انتشار بعدی همین حالا» در صف).
6. سازنده هر وقت بخواهد پک را برمی‌دارد؛ تو یا بررسی‌کننده‌ها هم «🗑 حذف از کانال» دارید. تلگرام فقط پست‌های
   کمتر از ۴۸ ساعت را پاک می‌کند؛ پست قدیمی‌تر فقط دکمه‌هایش برداشته می‌شود.

**بررسی‌کننده‌ها**: «📢 کانال انتشار» ← «👮 بررسی‌کننده‌ها» ← «➕ افزودن» و آیدی عددی، @یوزرنیم یا یک
پیام فورواردی از او. باید قبلاً ربات را استارت کرده باشد. بررسی‌کننده با `/admin` فقط «📋 صف انتشار» را می‌بیند
و به بقیه‌ی پنل دسترسی ندارد.

## استودیو (فاز ۲)

- کاربر عکسی را در چت می‌فرستد ← دکمه‌های «🎨 باز کردن در استودیو» و «⚡️ استیکر سریع».
  استودیو از دکمه‌ی منوی ربات («🎨 استودیو») و `/studio` هم باز می‌شود و آن‌جا عکس از گالری انتخاب می‌شود.
- در استودیو: حذف خودکار پس‌زمینه روی خود گوشی (و «حالت آدم» برای عکس آدم‌ها)، پاک‌کن و برگردان، شکل‌ها،
  دورخط و سایه، متن فارسی و انگلیسی با سه فونت، برگرداندن (↶) و دوباره (↷)، و ذخیره در یک پک، پک جدید یا فقط
  فرستادن در چت. تا کاربر ذخیره نزند چیزی از گوشی‌اش بیرون نمی‌رود.
- **یک کار در BotFather (فقط یک بار):** BotFather ← @Wanger_Motionbot ← Bot Settings ← Configure Mini App
  ← آدرس `https://app9292593567.tgcloud.ai/` را به‌عنوان Main Mini App بگذار. (دکمه‌ی منو را خود ربات تنظیم می‌کند.)
- اگر لازم شد استودیو را خاموش کنی: `/admin` ← ⚙️ تنظیمات ← 🚩 قابلیت‌ها ← «استودیو».
- صفحه‌ی تست دستگاه فاز ۰ حالا از پنل باز می‌شود: «🧪 تست دستگاه».

## ویدیو، GIF و واتس‌اپ (فاز ۳)

- **ورودی‌ها**: کاربر ویدیو، GIF، ویدیوی دایره‌ای، استیکر ویدیویی یا استیکر متحرک (TGS) می‌فرستد و دکمه‌های مناسب
  همان فایل را می‌گیرد: «🎬 استیکر ویدیویی»، «⚡️ استیکر ویدیویی سریع (۳ ثانیه‌ی اول)»، «🌀 ساخت GIF / تبدیل» و
  «🟢 استیکر متحرک واتس‌اپ». دکمه‌ی منوی ربات («🎨 استودیو») حالا صفحه‌ی اصلی استودیو را باز می‌کند با همه‌ی حالت‌ها.
- **استیکر ویدیویی تلگرام**: برش (شروع/پایان، حداکثر ۳ ثانیه)، سرعت، برعکس، رفت‌وبرگشت، حلقه‌ی نرم، کادر مربع،
  شکل دایره/گوشه‌گرد، پس‌زمینه‌ی شفاف یا رنگی و متن. خروجی VP9 با پس‌زمینه‌ی شفاف، ۵۱۲ پیکسل، ≤ ۲۵۶ کیلوبایت.
  ویدیوی دایره‌ای خودش گرد و گوشه‌هایش شفاف می‌شود.
- **GIF و تبدیل**: «🎞 GIF تلگرام» (MP4 بی‌صدا)، «📎 فایل .gif»، «🖼 WebP متحرک»، «🗂 فریم‌ها (ZIP)» و
  «🖼 فریم اول ← استیکر ثابت».
- **واتس‌اپ**: استیکر ثابت (از عکس) و متحرک (از ویدیو/GIF)، هر پک ۳ تا ۳۰ استیکر، ثابت و متحرک جدا، ۱ تا ۳ ایموجی،
  اسم پک و اسم سازنده. آیکون پک خودکار از اولین استیکر ساخته می‌شود. وقتی پک دست‌کم ۳ استیکر دارد، ربات فایل ZIP
  را می‌فرستد. واتس‌اپ خودش ZIP را باز نمی‌کند؛ کاربر آن را با یک برنامه‌ی واردکننده‌ی استیکر باز می‌کند (راهنمای
  ربات هیچ برنامه‌ی خاصی را معرفی نمی‌کند). در چت: «🗂 پک‌های من» ← «🟢 پک‌های واتس‌اپ».
- **چند استیکر از یک عکس**: اسکرین‌شات یک پک یا برگه‌ی استیکر ← ربات کادرها را پیدا و شماره‌گذاری می‌کند ← کاربر
  هر کادری را نخواهد کنار می‌گذارد ← همه یک‌جا به یک پک می‌روند. **چند عکس با هم**: تا ۳۰ عکس با یک تنظیم.
- **قابلیت‌های تازه در «🚩 قابلیت‌ها»**: «استیکر ویدیویی»، «استودیو GIF و MP4»، «تبدیل فرمت»، «پک واتس‌اپ»
  (همه روشن)، «فایل .wastickers» و «فایل GIF داخل ZIP» (خاموش).
  - «.wastickers» را فقط وقتی روشن کن که روی گوشی امتحانش کرده باشی (یک پک بساز، فایل را با برنامه‌ی
    واردکننده باز کن).
  - «فایل GIF داخل ZIP» را فقط اگر دیدی تلگرام «📎 فایل .gif» را به GIF معمولی تبدیل می‌کند روشن کن.
- **سهمیه‌های تازه در «⚙️ تنظیمات»**: «سهمیه‌ی GIF و فایل» (۱۰۰ در روز) و «سهمیه‌ی خروجی واتس‌اپ» (۲۰ در روز).
- **آیفون**: اگر تلگرام آیفون نتواند ویدیوی VP9 بسازد، استودیو همین را می‌گوید و GIF یا واتس‌اپ را پیشنهاد می‌کند.
  اگر چنین شد، خبرم کن تا ساخت libvpx WASM را (که تأییدش کرده بودی) شروع کنم.

## راه‌اندازی و به‌روزرسانی (برای اجرای Claude یا خودت)

```bash
cd wanger-stickers
npm install
npm test                               # همه‌ی تست‌ها باید سبز باشند
npm run tg -- migrate --local --dry-run   # دیدن تغییرات دیتابیس (چیزی اعمال نمی‌شود)
npm run tg -- migrate --local --safe      # ساخت جدول‌ها (فقط با تأیید تو)
npm run deploy                            # build + push (فقط با تأیید تو)
```
